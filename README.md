# เว็บไซต์สถาบันเสริมทักษะหฤทัยจุทาราชห์

เว็บไซต์ภาษาไทย 3 หน้าที่แก้ไขได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build

## เปิดใช้งาน

วิธีง่ายที่สุด: เปิด `dist/index.html` ด้วยเว็บเบราว์เซอร์ แล้วกดลิงก์เปลี่ยนหน้าได้ทันที

วิธีดูผ่านเครื่องตัวเอง (แนะนำสำหรับทดสอบปุ่มคัดลอก): ติดตั้ง Node.js แล้วเปิด Terminal ในโฟลเดอร์โปรเจกต์ สั่ง `npm start` จากนั้นเปิด `http://127.0.0.1:4173` หยุดด้วย Ctrl+C

## แก้ไขข้อมูล

- `dist/index.html` — หน้าแรก ประวัติผู้สอน การศึกษา และแนวทางการเรียน
- `dist/courses.html` — วิชา ตารางเรียน ค่าเรียน และสิ่งที่ได้รับ
- `dist/contact.html` — โทรศัพท์ LINE และค้นหาชื่อสถาบันบน Facebook
- `dist/styles.css` — สี ขนาดตัวอักษร การจัดวาง และภาพเคลื่อนไหว
- `dist/app.js` — เมนูมือถือและปุ่มคัดลอก LINE ID
- `dist/assets/teacher.png` — รูปอาจารย์จากไฟล์แนบ
- `dist/assets/emblem.png` — ตราสถาบันจากไฟล์แนบ

แก้ด้วยโปรแกรมแก้ไขข้อความและบันทึกเป็น UTF-8 หากเปลี่ยนข้อมูลที่ใช้ร่วมกัน เช่น เบอร์โทรหรือเมนู ให้แก้ทั้ง 3 หน้า รูปภาพเป็นไฟล์จริงที่รวมมากับโปรเจกต์ ไม่มีการอ้างอิงภาพชั่วคราวจากแชท

## เผยแพร่สู่เว็บไซต์สาธารณะ

นำ **ไฟล์ทั้งหมดภายใน `dist/`** ขึ้นไปยังโฟลเดอร์รากของบริการโฮสต์เว็บไซต์แบบ static โดยให้ `index.html` อยู่ที่ราก พร้อม `courses.html`, `contact.html`, `styles.css`, `app.js` และโฟลเดอร์ `assets/` ไม่ต้องมีระบบหลังบ้าน ฐานข้อมูล หรือ build command เปิด HTTPS เพื่อรองรับปุ่มคัดลอก LINE ID

หากใช้บริการที่รับ Git repository ให้ตั้ง Publish/Output directory เป็น `dist` และไม่ต้องสั่ง build ไฟล์ `.openai/hosting.json` ใช้สำหรับการเผยแพร่ผ่าน Sites เท่านั้น ไม่จำเป็นสำหรับโฮสต์อื่น

โปรเจกต์นี้เตรียม `vercel.json` สำหรับ Vercel แล้ว: Framework เป็น Other/ไม่มี framework, ไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build และใช้ Output Directory เป็น `dist` เชื่อม repository `win123456/learning` และใช้ `main` เป็น production branch เพื่อเผยแพร่เมื่อมีการ push

## รายละเอียดที่ควรทราบ

- ไม่มีฟอร์มสมัครเรียน ปุ่มโทรใช้ `tel:0850210553` และปุ่ม LINE ใช้ `https://line.me/ti/p/~reaw2525` การเปิดลิงก์ขึ้นอยู่กับอุปกรณ์ แอป LINE และการอนุญาตให้เพิ่มเพื่อนด้วย ID จึงมี ID ให้คัดลอกด้วย
- Facebook ลิงก์ไป **ผลค้นหาชื่อสถาบัน** เพราะยังไม่ได้รับ URL เพจจริง หากมี URL ให้เปลี่ยนลิงก์ใน `contact.html`
- ยังไม่ได้รับที่อยู่ จึงแนะนำให้สอบถามสถานที่เรียนทางโทรศัพท์หรือ LINE ไม่มีพิกัดที่แต่งขึ้น
- ใช้ Noto Sans Thai จาก Google Fonts ซึ่งต้องมีอินเทอร์เน็ต หากโหลดไม่ได้จะใช้ Tahoma หรือฟอนต์ sans-serif ของเครื่อง
- ภาพหมีเป็น SVG ที่แก้ไขได้ใน `index.html` และเคลื่อนไหวด้วย CSS รองรับ `prefers-reduced-motion: reduce` เพื่อหยุดการเคลื่อนไหวอัตโนมัติ
- ไม่มีคำรับรอง ผลงาน หรือจำนวนปีประสบการณ์ที่ไม่ได้รับจากผู้ใช้
- ไม่เก็บข้อมูลผู้เข้าชม ไม่มี analytics หรือคุกกี้ติดตามที่เพิ่มโดยโปรเจกต์นี้
